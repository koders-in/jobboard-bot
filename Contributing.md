# Contributing to JobBoard Bot 🤝

Thank you for your interest in contributing to JobBoard Bot!

This is a community-driven project, and contributions of all sizes are welcome.

## What Can You Contribute?

You can contribute in many ways, including:

- Adding new job-source integrations
- Working with APIs or webhooks
- Improving job filtering
- Improving job categorization
- Improving Discord functionality
- Fixing bugs
- Adding tests
- Improving CI/CD
- Improving documentation
- Suggesting new features
- Reporting bugs or sharing ideas

A contribution does not have to be a large code change. Useful ideas, documentation improvements, testing, and bug reports are also valuable.

## Technology Requirement

This project uses **JavaScript**.

All new code contributions should be written in JavaScript so that the project maintains a consistent codebase.

## Contribution Process

### 1. Check the Issues

Look through the open Issues and find something you would like to work on.

Issues marked with `good first issue` are suitable for people making their first contribution.

### 2. Discuss Your Idea

If your idea is not already listed as an Issue, create a new Issue before starting significant work.

This helps avoid duplicate work and allows the community to discuss the proposed change.

### 3. Fork the Repository

Create your own fork of the repository if you do not have direct write access.

### 4. Create a Branch

Create a separate branch for your work.

Example:

```bash
git checkout -b feature/job-source
